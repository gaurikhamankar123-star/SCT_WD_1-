Spoke & Sundry: Responsive Landing Page

Task 01 of my Web Development internship at SkillCraft Technology.

About Spoke & Sundry

Spoke & Sundry is a fictional neighbourhood bicycle repair and maintenance shop. The website is designed as a modern online presence for a local bike repair shop, where customers can learn about the services offered, explore the shop, and easily get in touch.

The landing page focuses on creating a simple, friendly, and responsive experience for local customers looking for bicycle repair, maintenance, and related services.

Features

- Fixed navigation bar, visible on every section while scrolling
- Navigation turns from transparent to solid and shrinks after scrolling
- Hover effect on every menu item
- Active link highlights the section currently on screen
- Hamburger menu with dropdown on mobile and tablet
- Smooth scrolling between sections
- Interactive hero wheel that rotates as you scroll
- Contact form with validation and error messages
- Fully responsive on mobile, tablet, and desktop

Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript (Vanilla JavaScript, no libraries)

Project Structure

├── index.html   # Page structure and content
├── style.css    # Styling and responsive layout
└── script.js    # Navigation, wheel animation and form validation

How to Run

1. Download or clone this repository.
2. Open "index.html" in any web browser.
3. Alternatively, in VS Code, right-click "index.html" and choose Open with Live Server.
